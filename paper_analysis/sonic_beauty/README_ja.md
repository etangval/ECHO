# ECHO：論文の解析・作図コード一式

ECHO（Event-Conserving Harmonic Optimisation）の論文解析パッケージです。
リポジトリ内の配置先は `paper_analysis/sonic_beauty/` です。

## 実行

Python 3.12を使用しました。このフォルダで次を実行します。

```bash
python -m pip install -r requirements.txt
python run_all.py
```

25選択項目の座標、99回ずつのシャッフル対照、数式の検算、アンケートの
集計値に基づく検定、英語の主図5点・補足図1点を再計算します。
シャッフル対照の再計算を省く場合は `python run_all.py --quick` です。
依存ライブラリの導入後は、ネット接続なしで実行できます。

- `keyboard/`：解析コード、実際の入力音符、参照値、出典・利用条件。
- `figures/`：現行の図、作図コード、アンケート集計値・検定結果・図注。
- `validation/`：再実行時のログと検証結果。
- `workflow_archive/`：採譜・音符抽出に使った元作業用コードの記録。

比較図は25曲・選択項目の冒頭抜粋です。ベルクは修正した冒頭8小節、
ウェーベルンは第I楽章の14小節と第II・III楽章の8小節を使っています。
第I楽章の延長は、4つの時間尺度を同じ定義で計算するためです。
ウェーベルンは全3楽章の計算結果も `keyboard/extensions/` にあります。
ベルクの全曲版の修正は完了していません。
アンケートは集計値からの正確な符号検定、Holm補正、95%信頼区間を
再現します。個票からの順序尺度解析・調整解析・ブートストラップの
再現コードを含むものではありません。

`analysis_parameters.json` は使用設定の記録です。値を変える場合は、
対応するPythonコードの定数も変更する必要があります。
アンケートの入力値は `figures/make_figures.py` の `counts` 辞書にあり、
CSVはその出力です。CSVだけを編集しても検定の入力は変わりません。
